# PSE Research Papers

Private research-paper collection exported read-only from Zotero’s `Export-to-github` collection.

## Organization

`papers/<year>/<FirstAuthor>_<Year>_<ShortTitle>_<ZoteroKey>/` contains a renamed PDF and `metadata.json`.

The Zotero key prevents filename collisions. Undated records use `Undated`. Original titles and filenames are preserved in metadata; names are shortened and sanitized only for filesystem use.

Bibliographic item types are retained, including theses and conference papers. Files have not been reclassified as peer-reviewed publications.

## Export integrity

42 bibliographic records; 42 PDFs. Every PDF copy was verified against its source with SHA-256.

Zotero originals were not moved, renamed or modified. Local storage paths, personal notes, annotations and authentication credentials are excluded. Bibliographic abstracts and tags are included when available.

Identical files and duplicate bibliographic records are retained rather than silently discarded; item keys distinguish them.

Publication metadata is preserved as supplied by Zotero. Missing bibliographic fields are left absent rather than guessed.
